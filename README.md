Najważniejsza poprawka:
- „Zimna woda i odprowadzenie ścieków” = zużycie zimnej wody + zużycie ciepłej wody,
- „Ciepła woda (podgrzanie)” = osobno zużycie ciepłej wody,
- CO = osobno zużycie GJ.

Dane przykładowe:
- okres zaliczek: marzec–sierpień 2026, 6 miesięcy,
- zimna woda: 43,088 → 62,330 m³,
- ciepła woda: 42,237 → 55,120 m³,
- CO: 10,463 → 10,619 GJ,
- stawki: 14,86 zł/m³; 28,00 zł/m³; 125,00 zł/GJ,
- zaliczki miesięczne: 63,90 zł; 61,60 zł; 62,50 zł.
