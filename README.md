# Rozliczanie najmu v1.4

Nowe funkcje:
- Import JSON — wczytuje wcześniej wyeksportowane rozliczenie.
- Pobierz PDF — przygotowuje czysty dokument rozliczenia i otwiera systemowe zapisanie do PDF.
- PDF zawiera dane lokalu/najemcy, odczyty, media, dodatkowe koszty, kaucję i końcową kwotę.
- Cache busting v14.

Uwaga: przeglądarka internetowa ze względów bezpieczeństwa nie może zapisać PDF na dysk całkowicie bez systemowego okna zapisu/drukowania bez dołączania zewnętrznej biblioteki PDF. Ten przycisk przygotowuje dokument specjalnie do PDF i uruchamia zapis.
