# Rozliczanie najmu v1.5

Przycisk „Pobierz PDF” generuje teraz plik PDF bezpośrednio w przeglądarce.
Nie korzysta z okna drukowania, więc w PDF nie pojawiają się:
- adres strony,
- źródło / URL,
- data i godzina z nagłówka przeglądarki,
- automatyczne nagłówki i stopki.

PDF zawiera odczyty, media, dodatkowe koszty, kaucję i wynik końcowy.
Import i eksport JSON pozostają dostępne.

Podmień na GitHubie wszystkie 3 pliki:
- index.html
- style.css
- app.js
